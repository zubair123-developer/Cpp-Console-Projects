# C++ Console Applications

A collection of functional C++ console applications demonstrating core programming fundamentals, logical control structures, and mathematical implementations.

## Projects Included

### 1. Advanced Scientific Calculator
* **Features:** Standard arithmetic, exponents, trigonometric functions (with Degree/Radian handling), logarithms with custom bases, and input validation to prevent runtime errors (e.g., division by zero).

### 2. Multi-Mode Tic-Tac-Toe Game
* **Features:** Offers both a local Two-Player mode and a Single-Player mode against an automated computer opponent. Built using a 2D matrix array, custom input validation, and game loop state management.
